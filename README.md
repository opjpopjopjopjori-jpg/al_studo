# Al Studio — تشغيل بدون مفاتيح API

يعمل الموقع مع **Ollama على السيرفر** بدلاً من Gemini، ولا يحتاج المستخدم أو الموقع إلى مفتاح API. هذا لا يعني أنه يعمل بدون نموذج: يجب تثبيت Ollama وتنزيل نموذج يدعم النص والصور، وتوفير ذاكرة ومعالج أو GPU مناسبين. نموذج `qwen2.5vl:7b` الافتراضي مجرد نقطة بداية؛ دقته وسرعته وشموليته ليست مضمونة، خصوصاً مع ملفات طويلة أو صور طبية. لا تعتبر الملخصات تشخيصاً أو بديلاً عن مراجعة المصادر الأصلية.

## التشغيل

1. ثبّت Node.js 22 أو أحدث و[Ollama](https://ollama.com/download) على السيرفر.
2. شغّل خدمة Ollama على واجهة خاصة؛ ثم نزّل النموذج مرة واحدة: `ollama pull qwen2.5vl:7b`.
3. ثبّت الحزم: `npm ci`، ثم ابنِ الواجهة: `npm run build`.
4. شغّل `NODE_ENV=production npm start`، وافتح منفذ `PORT` (الافتراضي 3000). أو للتطوير: `npm run dev`.

يمكن نسخ `.env.example` إلى `.env.local` لتعديل عنوان Ollama والنموذج والحدود. عند نشر الموقع على الإنترنت، يحتاج السيرفر إلى تشغيل Node وOllama والنموذج معاً، أو الاتصال بخدمة Ollama خاصة موثوقة. تنزيل النموذج يستلزم إنترنت ومساحة كافية؛ الاستضافة والموارد قد تكون مدفوعة. لا تضع عنوان Ollama على واجهة عامة؛ منفذه لا يحتوي حماية مدمجة. لا يلزم أي مفتاح، لكن واجهات التطبيق غير محمية بتسجيل دخول، لذا أضف مصادقة وتحديد طلبات وحدود حجم وحماية من إساءة الاستخدام قبل إتاحتها للعامة.

## حدود مهمة

- تُستخرج نصوص PDF النصية أولاً، وتُرسل الصفحات التي لا تحتوي نصاً كصور. لا يرى النموذج الرسومات المضمنة في الصفحات النصية إلا عند تفعيل «تحليل صور كل صفحات PDF» قبل رفع الملفات. إعادة الرفع مطلوبة بعد تغيير الخيار. الحد الافتراضي 16 صورة في الطلب، وهو قابل للضبط؛ قسّم الملفات الكبيرة. يتطلب تحليل الصور نموذجاً متعدد الوسائط.
- هناك حد تقريبي لطول الإدخال ورسالة خطأ عند تجاوزه، لكن تقطيع النماذج وسياق الصور يختلفان؛ لا يمكن ضمان عدم إسقاط جزء من سياق كبير. راجع جميع المخرجات وقسّم الملفات. التدقيق الثنائي هو تعليمات للنموذج وليس ضماناً للشمولية.
- البحث المباشر في Google لم يعد مدعوماً لأن النموذج المحلي لا يمتلك أداة البحث؛ لن نعرض إجاباته على أنها نتائج ويب. إنشاء Google Form يتطلب تسجيل دخول Google من جهة المستخدم كالسابق.
- مسارات `/api/gemini` القديمة أبقيناها للتوافق مع الواجهة فقط؛ جميع طلبات التوليد تستخدم Ollama، و`/api/ai/status` يعرض حالة الخدمة والنموذج.
